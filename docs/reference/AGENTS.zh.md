# reference 指南

参考页是查阅表，不是叙述。它给具体形状一个唯一权威位置，避免多篇文档各抄一份。

## 文件

- [`errors.zh.md`](errors.zh.md) —— `ConfigError` 每个变体：字段、触发条件、消息原文

## 规则

- 一页只放一类具体对象：一个错误类型、一张 API 签名表、一份环境变量清单。
- 参考页对描述的对象是规范；代码实现是另一半。链到代码，不重复实现细节。
- 每一行都要能脱离上下文使用：写清场景、字段、触发条件和输出。
- 代码变了，同一次改动里更新参考页；其他文档链到这里，不复制表格。
- 新增文件后在本文件登记。
