# plan guide

Plan documents say "what to do next". They are not a contract and can change at
any time.

## Files

- [`roadmap.md`](roadmap.md) — feature directions, progress, acceptance
- [`doc-system.md`](doc-system.md) — how the documentation system changes step by step

## Rules

- Status uses ✅ / 🚧 / ⬜; every plan states "what acceptance is possible when
  it is done".
- When the direction changes, change the plan; do not treat an outdated plan as
  a contract.
- Register new plan files in this file.
