# 修改 write-docs 自身

本 skill 分两层：`SKILL.md` 是通用写作方法，触发后整篇进入上下文；`references/` 按文档类型一份，只在写那一类文档时才读。改这个 skill 就是决定一条内容该进哪一层。

- 只有对任何文档都成立的规则才写进 `SKILL.md`；绑定了某类文档的规则一律放 `references/` 下对应文件。
- 新增一种文档类型：在 `references/` 建一个文件，写清读者是谁、结构、该写什么、不该写什么，再到 `SKILL.md` 的「按文档类型」加一行链接。三步缺一不可，否则这份规范不会被读到。
- 内容能并入已有条目就并入，不要为相近的规则新开一条；两条在说同一件事时，改旧的那条并删掉新的。
- `description` 只在触发时机变化时改，写「什么时候用」，不写「里面有什么」。
- 与 `docs/`、`AGENTS.md` 重复的事实只留一处：删掉 skill 里的，换成链接。
- 自查：这条规则不做会写错文档吗？不会就删。
