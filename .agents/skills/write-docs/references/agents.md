# AGENTS.md

`AGENTS.md` 会被自动加载，内容常驻每次对话，篇幅就是成本。只写长期有效、不写就会做错的事。

- 根目录：`AGENTS.md`（英文）与 `AGENTS_ZH.md`（中文）成对，改一边就改另一边。
- 英文是权威版本；`docs/` 下的中文副本用 `*.zh.md`，改英文后同步中文。
- 写：项目是什么、设计约束、目录结构、工具流程（`moon fmt` / `moon info` / `moon test`）。
- 不写：文件清单、枚举值、命令矩阵这类读代码就知道的内容；进度、计划、一次性的改动记录。
- 不写具体设计决定（整数怎么存、错误消息怎么写、用了哪个派生）。它们会变，属于 `docs/design/` 和 `docs/decisions/`。
- 每条规则写完问一遍：不做这一步会错吗？不会就删。
- `docs/AGENTS.md` 只登记直接子目录和职责；具体文件登记在各自目录的 `AGENTS.md`。
- 新增子目录：在 `docs/AGENTS.md` 加一行，并在该目录建 `AGENTS.md`；新增文件先登记再写。
